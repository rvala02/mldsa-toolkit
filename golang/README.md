# Go Test Harness for ML-DSA Side-Channel Analysis Toolkit

This directory contains helper programs to perform timing analysis on Go's
standard library ML-DSA implementation (`crypto/internal/fips140/mldsa`).

## Building

1. Copy or symlink this directory under the Go source tree (the `mldsa` package
   is internal to `crypto` and cannot be imported from a normal module path):

```console
$ cp -r golang $GOROOT/src/crypto/mldsa_timing
$ cd $GOROOT/src/crypto/mldsa_timing
```

2. Compile the harness (each file is its own `main` package):

```console
$ go build -o timing timing.go
$ go build -o timing_no_encode timing_no_encode.go
$ go build -o key_timing key_timing.go
$ go build -o key_timing_no_encode key_timing_no_encode.go
$ go build -o rejection_timing rejection_timing.go
$ go build -o rejection_timing rejection_timing.go
```

Use a Go toolchain that actually ships `crypto/internal/fips140/mldsa`.

## Usage

### Timing with a single key seed

The `timing` harness signs concatenated messages with one ML-DSA private key derived from a 32-byte seed.

```console
$ ./timing -i messages.bin -o raw_times.csv -k seed.bin -s signatures.bin -m 44
```

Arguments:
```
-i file     File with concatenated messages to sign 
-o file     File where to write timing data 
-k file     File with a 32-byte ML-DSA key seed 
-m num      ML-DSA parameter set: 44, 65, or 87
-s file     File where to write signatures (optional)
```

### Timing without signature encoding

The `timing_no_encode` harness is used like `timing`, but stops before the final signature encoding step.

```
$ ./timing_no_encode -i messages.bin -o raw_times.csv -k seed.bin -s signatures.bin -m 44
```

### Timing with per-sample key seeds

The `key_timing` harness signs each message with a corresponding ML-DSA private key derived from a concatenated seed file.

```
$ ./key_timing -i messages.bin -o sigs.bin -t raw_times.csv -k schedule.bin -s signatures.bin -n 32 -m 44
```

Arguments:
```
-i file     File with concatenated messages to sign 
-o file     File where to write raw signatures 
-t file     File where to write timing data 
-k file     File with concatenated 32-byte ML-DSA key seeds 
-n num      Length of each message in bytes 
-m num      ML-DSA parameter set: 44, 65, or 87
-s file     File where to write signatures (optional)
```

### Timing with per-sample key seeds without signature encoding

The `key_timing_no_encode` harness is used like `key_timing`, but excludes the final signature encoding step from the measured operation.

```
$ ./key_timing_no_encode -i messages.bin -o sigs.bin -t raw_times.csv -k schedule.bin -n 32 -m 44
```

### Timing rejection-window test vectors

The `rejection_timing` harness is used with test vectors generated by the [rejection test-case generator](../scripts/rejection_tc_generator.py). 

```
$ ./rejection_timing -i messages.bin -k keys.bin -e signatures.bin -t raw_times.csv -n 32 -m 44
```

Arguments:
```
-i file     File with concatenated messages to sign 
-k file     File with concatenated 32-byte ML-DSA key seeds 
-e file     File with expected deterministic signatures (optional) 
-o file     File where to write produced signatures (optional) 
-t file     File where to write timing data 
-n num      Length of each message in bytes 
-m num      ML-DSA parameter set: 44, 65, or 87
```

The `-e` option can be used to verify that Go produces the same deterministic signatures as the generator. If `-o` is provided, the produced signatures are written to that file. If `-o` is omitted, only timing data is written.

### Timing rejection-window test vectors without signature encoding

The `rejection_timing_no_encode` harness is used like `rejection_timing`, but excludes the final signature encoding step from the measured operation.

```
$ ./rejection_timing_no_encode -i messages.bin -k keys.bin -e signatures.bin -t raw_times.csv -n 32 -m 44
```

## Limitations

Keys must be **32-byte binary seeds** (what `NewPrivateKey*` accepts). 

The `*_no_encode` programs expect a patched `SignDeterministic` that returns an extra timing value for the internal signing core.
